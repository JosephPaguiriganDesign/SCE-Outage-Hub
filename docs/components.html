Property card (F7 portfolio, round 8)

F7 property cards are the shared status card: same header (Current Power Status: ON/OFF), icon + ALL-CAPS label + event chip on the title line, then the property address and a one-line status. The whole card is one link (a.cps.cps-prop, 48dp+ target, focus ring, accessible name = address + state); there is no “Open dashboard” link, no left colour bar and no button inside. No toggle, stepper or trust line in the list variant (the dashboard it opens has them; the portfolio summary carries “Last updated”). One card per state:
